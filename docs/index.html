A computational neuroscience mini-project

Tracing a fly’s visual-to-motor route

Using Janelia’s MaleCNS connectome, we queried shortest paths from a visual neuron (R1–R6) to a descending neuron (DNg13), then asked how those paths change when low-count connections are filtered out.

What we did

We used neuPrint to request a shortest route for the same R1–R6 and DNg13 body IDs at four minimum synapse-count filters. The separate HTML animation illustrates a pulse along one queried route. It is a schematic, not a neural dynamics simulation.

What this does not show

This is a graph-structure result for one endpoint pair. Synapse counts are not calibrated physiological strengths. “No path returned” is limited to the query criteria; it does not prove no biological communication.

Project summary
Built a Python connectomics analysis using Janelia’s MaleCNS neuPrint API; queried a visual-to-descending-neuron route and evaluated shortest-path sensitivity to synapse-count filtering, with explicit limits separating connectome structure from simulated activity.
